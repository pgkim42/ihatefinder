- 위치 미상 작업은 범위 검색을 먼저 올리는 조건부 분기로 남았고, 검색의 완료 계약은 source dossier에 유지된다: 범위/원래 경로 표시, 취소, 불완전 탐색 처리, 부모 폴더 열기·항목 선택, 기존 복사·이동 연결. Spotlight와 자체 재귀 검색도 하나의 요구로 합치지 않는다.
- 부분 실패 작업은 결과 action을 먼저 올리되, 이는 안전 엔진 재작성이나 queue가 아니라 최근 결과 재열기·살아 있는 위치 열기/선택·상태별 다음 행동이라는 전용 recovery UI increment다. 기존 진행·취소·부분 결과·보수적 undo와 수동 cut 재시도 반례를 보존한다.

조건부 순위: 공통으로 기존 action 노출/거르기 명료화 → 기본 다음 후보는 내 장소. 위치 미상이 주작업이면 범위 검색, A/B/C 상태 보존이 주작업이면 추가 자리, 부분 실패 복구가 주작업이면 결과 action을 각각 먼저 둔다. 최근 picker·주소 후보·기존 자리 선택/스크롤 개선은 해당 장면에 맞춰 독립적으로 선택한다. 이는 사용 빈도나 원인 측정 결과가 아닌 제품 판단이다.
