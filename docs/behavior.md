# 동작

용어는 [CONTEXT.md](../CONTEXT.md)에 있다. 보이는 동작의 기준은 이 파일이다. 동작을 바꿀 때는 코드보다 이 파일을 먼저 고친다.

포커스가 글상자에 있으면 그 글상자가 키를 가져간다. 주소창을 고치는 중이거나 이름을 바꾸는 중에는 Enter가 그 편집을 확정하고, Esc가 편집을 취소한다.

## 이동

1. 폴더 항목을 더블클릭하거나, 목록에서 Enter 또는 Cmd+Down을 누르면 그 폴더로 들어간다.
2. 파일 항목에서 같은 조작을 하면 그 파일의 기본 앱이 연다.
3. 위(Cmd+Up, Alt+Up)는 부모 폴더로 간다. 볼륨 최상위에서는 그 경로에 머문다. 더 이상 올라갈 부모가 없기 때문이다.
4. 뒤로(Alt+Left, Cmd+[)와 앞으로(Alt+Right, Cmd+])는 그 세션이 방문한 경로만 오간다. 맥 키보드의 Delete 키는 Backspace와 같은 키라, 뒤로에는 쓰지 않는다.
5. 사이드바는 위치와 디스크 두 구역으로 나뉜다. 위치는 홈, 데스크탑, 문서, 다운로드, 응용 프로그램이다. 디스크는 맥 본체 디스크, 외장 디스크, 디스크 이미지만 보여 준다. Preboot처럼 시스템이 숨기는 내부 볼륨은 빠진다. 구역 제목은 눌러도 이동하지 않는다. 위치를 고르면 포커스 창이 그곳으로 간다.
6. 권한이 없거나 경로를 읽지 못하면 해당 창 아래에 실패한 경로와 이유를 보여주고 이전 경로와 목록에 남는다. 맥이 띄우는 권한 창은 맥의 것이다.

## 주소창

Cmd+L 또는 Ctrl+L, 또는 주소창 클릭으로 전체 경로를 직접 고친다. Enter로 이동한다. 읽을 수 없는 경로면 해당 창 아래에 오류를 보여주고 편집 전 경로와 목록에 남는다.

## 상세 목록

열은 이름, 수정한 날짜, 종류, 크기다. 이름에는 확장자가 항상 보인다. 행에는 그 항목의 아이콘이 보인다.

이름 정렬은 폴더를 파일보다 위에 두고, 같은 종류 안에서는 대소문자를 구분하지 않고 이름 순이다. 열 머리 클릭은 그 열의 오름차순과 내림차순을 바꾼다.

숨김 항목은 기본으로 빠진다. 숨김은 이름이 `.`으로 시작하거나 Finder 숨김 표시가 된 항목이다. Cmd+Shift+. 와 Ctrl+Shift+. 가 표시를 뒤집는다.

상태 막대는 현재 폴더의 항목 수와, 선택한 파일 크기의 합을 보여 준다. 폴더는 크기 합에서 뺀다. 폴더 용량을 세려고 하위 전체를 읽지 않기 위해서다.

긴 폴더를 스크롤해도 창이 멈춘 채로 남아 있지 않는다. 아이콘은 화면에 보이는 행만 읽는다.

폴더 조회와 정렬은 화면 스레드 밖에서 수행한다. 각 창은 불러오는 경로와 실패 이유를 표시한다. 연속으로 다른 폴더를 열면 마지막 요청만 경로·목록·이동 이력에 반영한다.

현재 폴더의 외부 생성·삭제·이름 변경과 파일 내용 변경을 감지해 목록을 갱신한다. 선택은 행 번호가 아닌 파일 URL로 유지하고, 사라진 파일은 선택을 해제한다. 이름 편집 중에는 목록 교체를 미루고, 주소 편집 중에는 입력한 글자를 덮어쓰지 않는다.

## 선택과 이름

클릭은 그 항목만 선택한다. Shift+클릭은 범위, Cmd+클릭과 Ctrl+클릭은 하나씩 더하거나 뺀다. Cmd+A와 Ctrl+A는 보이는 항목을 모두 선택한다.

목록에 포커스가 있고 이름을 바꾸는 중이 아닐 때, 글자를 치면 그 글자로 시작하는 이름으로 점프한다.

F2와 느린 클릭은 포커스된 항목의 이름을 고친다. 확정한 이름이 기존 항목과 겹치면 아래 이름 충돌과 같은 선택을 쓴다.

## 클립보드

Cmd와 Ctrl 모두 C는 복사, X는 잘라두기, V는 붙여넣기다.

잘라둔 항목이 현재 폴더에 아직 있으면 흐리게 보인다. Esc는 이동 의도만 해제하고 파일 URL은 일반 복사로 남긴다. 파일은 옮기지 않는다. 붙여넣을 파일이 없으면 폴더는 그대로다.

붙여넣기 대상은 포커스 창의 현재 폴더다.

- 복사 후 붙여넣기는 복제한다.
- 잘라두기 후 붙여넣기는 옮긴다.
- 잘라둔 항목을 원래 폴더에 다시 붙여넣으면 파일은 그대로 두고 잘라두기만 해제한다.

Finder와 시스템 파일 URL 클립보드로 복사를 주고받는다. 외부에서 복사한 파일은 이동이 아닌 복사로 취급한다. 일반 텍스트·원격 URL·지원하지 않는 항목이 섞인 클립보드는 파일 작업으로 실행하지 않는다.

다른 앱이나 새 복사·잘라두기가 클립보드를 바꾸면 이전 잘라두기 의도는 무효가 된다. 작업 시작 시 원본·목적지·클립보드 세대를 고정한다. 완료 시 같은 세대의 성공한 이동 항목만 잘라두기에서 빼고, 건너뜀·실패·취소·미처리 항목은 남긴다. 이전 작업 완료가 새 클립보드를 지우지 않는다.

다른 디스크로의 이동은 복사가 끝난 뒤에만 원본을 휴지통으로 보낸다. 복사가 실패하면 원본은 그 자리에 남는다.

## 이름 충돌

같은 이름이 있으면 바꾸기, 건너뛰기, 둘 다 유지 중 하나가 정해지기 전에 쓰지 않는다. 바꾸기는 목적지 볼륨의 임시 위치에서 새 항목을 준비한 뒤 기존 항목을 보관하고 새 항목을 확정한다. 확정에 실패하면 원본과 기존 대상을 복구한다. 성공한 뒤 기존 항목을 휴지통으로 보낸다. 복구나 휴지통 처리가 실패하면 살아 있는 파일의 위치를 결과에 표시하고 보존한다. 같은 폴더에 원본을 다시 복사할 때 바꾸기는 그 원본을 그대로 둔다. 둘 다 유지는 `이름 (1)`, `이름 (2)`처럼 번호를 붙인다. 한 번의 붙여넣기에서 고른 답을 나머지 충돌에 적용할 수 있다.

## 파일 작업 상태와 취소

복사·이동은 작업 종류, 현재 파일, 처리 항목 수를 표시한다. 큰 파일은 현재 파일의 전송 바이트와 전체 바이트를 표시하고, 폴더 탐색·메타데이터·확정처럼 전체량을 모르는 구간은 불확정 진행 상태로 표시한다. 폴더 전체 진행률로 오인할 백분율은 표시하지 않는다.

취소 버튼은 파일 하나를 복사하는 도중에도 작동한다. 아직 확정하지 않은 복사본은 정리하고 원본과 기존 대상을 보존한다. 이미 시작한 확정·복구 구간은 중간에 끊지 않고 안전하게 마친다. 완료한 항목은 유지하며, 취소된 항목과 아직 시도하지 않은 항목을 구분한다.

첫 실패나 취소 이후 나머지 항목은 실행하지 않는다. 결과 창은 완료·건너뜀·실패·취소·미처리와 각각의 원본·목적지·복구 위치를 보여준다. 새 대상은 완성됐지만 이전 대상의 휴지통 이동이 실패한 경우도 경고를 표시한다. 다른 디스크에서 원본을 휴지통으로 보내지 못했다면 양쪽의 완성된 파일을 보존하고 실패로 보고한다.

파일 작업 중 추가 변경 명령은 이유를 안내하고 실행하지 않는다. 작업 중에는 창 닫기와 앱 종료도 완료 또는 취소 후 다시 시도하도록 안내한다.

## 휴지통과 만들기

목록에서 Mac의 Delete 키 또는 Cmd+Delete는 선택 항목을 휴지통으로 보낸다. 이름을 바꾸는 중이면 Delete는 글자를 지운다.

새 폴더는 Cmd+Shift+N 또는 Ctrl+Shift+N이다. 새 텍스트 파일은 Cmd+Alt+N 또는 Ctrl+Alt+N이다. 둘 다 우클릭 메뉴에도 있다. 기본 이름은 `새 폴더`와 `새 텍스트 문서.txt`다. 이미 있으면 `새 폴더 (2)`처럼 번호를 붙인다.

## 드래그

목록 행을 끌어 폴더 행이나 다른 세션의 목록에 놓으면 그 폴더로 옮긴다. 이동 규칙과 이름 충돌 규칙은 붙여넣기와 같다. Option을 누른 드롭은 복사한다. 조금만 움직여도 선택이 드래그로 바뀌지 않게, 일정 거리 이상 끌었을 때만 드래그가 시작된다.

## 양쪽 창

툴바에서 오른쪽 세션을 켜고 끈다. 목록이나 그 주소창을 누르면 그 세션이 포커스 창이 된다. 꺼져 있을 때 F5와 F6는 파일을 옮기지 않는다. 켜져 있을 때 F5는 포커스 창의 선택을 반대 세션으로 복사하고, F6는 옮긴다.

사이드바는 160–240pt 범위에서 유지하고 파일 창은 각각 최소 260pt를 확보한다. 양쪽 창을 켜면 가용 폭을 나눈다. 이름 열은 최소 180pt를 유지하며, 좁은 창에서는 나머지 열을 가로 스크롤로 본다.

## 다시 실행하기

좌우 창의 마지막으로 읽기에 성공한 경로, 정렬 열·방향, 숨김 표시와 양쪽 창 표시 여부를 저장한다. 진행 중인 탐색의 목적지는 저장하지 않는다. 다음 실행 시 저장된 경로를 비동기로 읽는다.

저장된 폴더에 접근하지 못하면 홈, 임시 폴더 순서로 서로 다른 후보를 한 번씩 시도하고 해당 창 아래에 복원 실패 이유와 대체 경로를 표시한다. 이후 사용자가 직접 이동하다 실패한 경우에는 자동으로 다른 폴더로 보내지 않는다. 잘라두기 의도와 진행 중인 파일 작업은 저장하거나 재실행하지 않는다.

## 이번 범위 밖

파일 작업이 없을 때 Cmd+W는 창을 닫는다. 마지막 창이 닫히면 앱이 끝난다.

탭, 아이콘 보기, 열 보기, 폴더 검색, 스페이스 미리보기, 실행 취소, 디스크에서 바로 지우기는 이 문서의 동작이 된 뒤에 이 파일을 고치면서 추가한다.
