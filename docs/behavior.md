# 동작

용어는 [CONTEXT.md](../CONTEXT.md)에 있다. 보이는 동작의 기준은 이 파일이다. 동작을 바꿀 때는 코드보다 이 파일을 먼저 고친다.

포커스가 글상자에 있으면 그 글상자가 키를 가져간다. 주소창을 고치는 중이거나 이름을 바꾸는 중에는 Enter가 그 편집을 확정하고, Esc가 편집을 취소한다. 글상자 안에서는 Cmd와 Ctrl 모두 C/X/V/A/Z가 글자 복사·잘라내기·붙여넣기·전체 선택·실행 취소이고 Shift+Z는 다시 실행이다. 편집 메뉴의 실행 취소·다시 실행은 글상자에 포커스가 있을 때 그 글상자의 글자 편집에 쓰인다.

## 이동

1. 폴더 항목을 더블클릭하거나, 목록에서 Enter 또는 Cmd+Down을 누르면 그 폴더로 들어간다. 폴더 하나만 골랐을 때만 들어간다.
2. 파일 항목에서 같은 조작을 하면 그 파일의 기본 앱이 연다. 여러 항목을 골랐고 파일이 있으면 파일을 모두 기본 앱으로 열고 폴더는 열지 않는다. 폴더만 여러 개 골랐으면 아무것도 하지 않고 이유를 보여준다. 파일을 20개 넘게 열 때는 먼저 묻는다.
3. 위(Cmd+Up, Alt+Up)는 부모 폴더로 간다. 볼륨 최상위에서는 그 경로에 머문다. 더 이상 올라갈 부모가 없기 때문이다. 위로 가면 방금 나온 폴더를 선택한다.
4. 뒤로는 Alt+Left, Cmd+[, 그리고 목록에서 Backspace(맥의 Delete 키)다. 앞으로(Alt+Right, Cmd+])와 함께 그 세션이 방문한 경로만 오간다. 글상자 안에서 Backspace는 글자를 지운다.
5. 사이드바는 즐겨찾기, 위치, 디스크로 나뉜다. 위치는 홈, 데스크탑, 문서, 다운로드, 응용 프로그램이다. 디스크는 맥 본체 디스크, 외장 디스크, 디스크 이미지만 보여 준다. Preboot처럼 시스템이 숨기는 내부 볼륨은 빠진다. 디스크 연결·해제는 NSWorkspace 알림으로 목록을 갱신한다. 구역 제목은 눌러도 이동하지 않는다. 위치를 고르면 포커스 창이 그곳으로 간다.
6. 권한이 없거나 경로를 읽지 못하면 해당 창 아래에 실패한 경로와 이유를 보여주고 이전 경로와 목록에 남는다. 맥이 띄우는 권한 창은 맥의 것이다.

파일 메뉴나 목록 우클릭의 `현재 폴더를 즐겨찾기에 추가`는 포커스 창의 현재 폴더를 사이드바에 등록한다. 같은 표준 경로는 한 번만 등록한다. 즐겨찾기 우클릭의 제거·위로 이동·아래로 이동은 목록만 바꾸며 원본 폴더를 옮기거나 지우지 않는다. 순서와 경로는 다음 실행에도 남는다. 저장된 폴더를 읽지 못하면 기존 탐색 실패 표시를 쓰고 현재 목록을 유지한다. 즐겨찾기는 절대 경로를 저장하며 외부에서 이름을 바꾸거나 폴더를 옮긴 뒤의 위치를 자동 추적하지 않는다.

즐겨찾기 문맥 메뉴의 첫 명령은 `즐겨찾기 열기`다. 이 명령도 포커스 창에서 해당 폴더를 열며, 제거·순서 조정과 별도의 비파괴 동작이다.

## 주소창

Cmd+L 또는 Ctrl+L, 또는 주소창 클릭으로 전체 경로를 직접 고친다. Enter로 이동한다. 읽을 수 없는 경로면 해당 창 아래에 오류를 보여주고 편집 전 경로와 목록에 남는다.

## 상세 목록

열은 이름, 수정한 날짜, 종류, 크기다. 이름에는 확장자가 항상 보인다. 행에는 그 항목의 아이콘이 보인다.

이름 정렬은 폴더를 파일보다 위에 두고, 같은 종류 안에서는 대소문자를 구분하지 않고 이름 순이다. 열 머리 클릭은 그 열의 오름차순과 내림차순을 바꾼다.

숨김 항목은 기본으로 빠진다. 숨김은 이름이 `.`으로 시작하거나 Finder 숨김 표시가 된 항목이다. Cmd+Shift+. 와 Ctrl+Shift+. 가 표시를 뒤집는다.

상태 막대는 현재 폴더의 항목 수와, 선택한 파일 크기의 합을 보여 준다. 폴더는 크기 합에서 뺀다. 폴더 용량을 세려고 하위 전체를 읽지 않기 위해서다.

긴 폴더를 스크롤해도 창이 멈춘 채로 남아 있지 않는다. 아이콘은 화면에 보이는 행만 읽는다.

폴더 조회와 정렬은 화면 스레드 밖에서 수행한다. 각 창은 불러오는 경로와 실패 이유를 표시한다. 연속으로 다른 폴더를 열면 마지막 요청만 경로·목록·이동 이력에 반영한다.

현재 폴더의 외부 생성·삭제·이름 변경과 파일 내용 변경을 감지해 목록을 갱신한다. 선택은 행 번호가 아닌 파일 URL로 유지하고, 사라진 파일은 선택을 해제한다. 이름 편집 중에는 목록 교체를 미루고, 주소 편집 중에는 입력한 글자를 덮어쓰지 않는다.

## 선택과 이름

클릭은 그 항목만 선택한다. Shift+클릭은 범위, Cmd+클릭과 Ctrl+클릭은 하나씩 더하거나 뺀다. Ctrl+클릭은 메뉴를 열지 않는다. 우클릭과 두 손가락 탭은 그대로 메뉴를 연다. Cmd+A와 Ctrl+A는 보이는 항목을 모두 선택한다.

목록에 포커스가 있고 이름을 바꾸는 중이 아닐 때, 글자를 치면 그 글자로 시작하는 이름으로 점프한다. Space는 이름 점프에 쓰이지 않고 미리보기를 연다.

F2와 느린 클릭은 포커스된 항목의 이름을 고친다. 이름 고치기를 시작하면 파일은 확장자를 뺀 이름만, 폴더와 `.`으로 시작하는 이름은 전체가 선택된다. 확정한 이름이 기존 항목과 겹치면 아래 이름 충돌과 같은 선택을 쓴다.

## 미리보기

목록에서 Space 또는 Cmd+Y는 선택 항목 미리보기를 열고 닫는다. 미리보기 창이 앞에 있어도 Space는 닫고, 위·아래 화살표는 목록 선택을 바꾸며 미리보기도 따라간다. Esc는 미리보기를 닫는다. 이름을 바꾸는 중이거나 글상자에 있을 때 Space는 글자다. 선택이 없으면 미리보기를 열지 않는다. 양쪽 창에서는 포커스 창의 선택을 보여주고, 포커스 창이 바뀌면 미리보기도 따라간다.

앱 보기 메뉴와 목록 우클릭의 `미리보기 (Space)`도 같은 미리보기를 연다. 선택이 없거나 이름을 편집하는 동안에는 실행하지 않는다.

## 이 폴더에서 이름 거르기

Cmd+F, Ctrl+F, F3는 포커스 창 목록 위에 거르기 칸을 연다. 글자를 치면 현재 폴더의 항목 중 이름에 그 글자가 들어간 것만 보인다. 대소문자와 악센트는 구분하지 않고, 앞뒤 공백은 무시한다. 칸이 비면 모두 보인다. 하위 폴더는 찾지 않는다.

편집 메뉴의 `이 폴더에서 이름 거르기`도 같은 칸을 연다. 재귀 검색을 뜻하지 않는다.

거르는 동안 상태 막대는 `N개 중 M개 표시`를 보여준다. 가려진 항목은 선택에서 빠지고, 복사·잘라두기·휴지통·F5·F6은 보이는 선택에만 작용한다. 목록이 외부 변화로 다시 읽혀도 거르기와 선택은 파일 기준으로 유지된다. Enter는 목록으로 포커스를 옮기고 거르기는 유지한다. Esc는 거르기를 지우고 칸을 닫고 목록으로 돌아간다. 다른 폴더로 이동하면 거르기는 지워진다. 새로 만든 항목이 거르기에 가려지면 거르기를 지우고 그 항목을 보여준다.

## 클립보드

Cmd와 Ctrl 모두 C는 복사, X는 잘라두기, V는 붙여넣기다.

잘라둔 항목이 현재 폴더에 아직 있으면 흐리게 보인다. Esc는 이동 의도만 해제하고 파일 URL은 일반 복사로 남긴다. 파일은 옮기지 않는다. 붙여넣을 파일이 없으면 폴더는 그대로다.

붙여넣기 대상은 포커스 창의 현재 폴더다.

- 복사 후 붙여넣기는 복제한다.
- 잘라두기 후 붙여넣기는 옮긴다.
- 잘라둔 항목을 원래 폴더에 다시 붙여넣으면 파일은 그대로 두고 잘라두기만 해제한다.

Finder와 시스템 파일 URL 클립보드로 복사를 주고받는다. 외부에서 복사한 파일은 이동이 아닌 복사로 취급한다. 일반 텍스트·원격 URL·지원하지 않는 항목이 섞인 클립보드는 파일 작업으로 실행하지 않는다.

다른 앱이나 새 복사·잘라두기가 클립보드를 바꾸면 이전 잘라두기 의도는 무효가 된다. 작업 시작 시 원본·목적지·클립보드 세대를 고정한다. 완료 시 같은 세대의 성공한 이동 항목만 잘라두기에서 빼고, 건너뜀·실패·취소·미처리 항목은 남긴다. 이전 작업 완료가 새 클립보드를 지우지 않는다.

다른 디스크로의 이동은 복사가 끝난 뒤에만 원본을 휴지통으로 보낸다. 복사가 실패하면 원본은 그 자리에 남는다.

## 이름 충돌

같은 이름이 있으면 바꾸기, 건너뛰기, 둘 다 유지 중 하나가 정해지기 전에 쓰지 않는다. 바꾸기는 목적지 볼륨의 임시 위치에서 새 항목을 준비한 뒤 기존 항목을 보관하고 새 항목을 확정한다. 확정에 실패하면 원본과 기존 대상을 복구한다. 성공한 뒤 기존 항목을 휴지통으로 보낸다. 복구나 휴지통 처리가 실패하면 살아 있는 파일의 위치를 결과에 표시하고 보존한다. 같은 폴더에 원본을 다시 복사할 때 바꾸기는 그 원본을 그대로 둔다. 둘 다 유지는 `이름 (1)`, `이름 (2)`처럼 번호를 붙인다. 한 번의 붙여넣기에서 고른 답을 나머지 충돌에 적용할 수 있다.

## 파일 작업 상태와 취소

복사·이동은 작업 종류, 현재 파일, 처리 항목 수를 표시한다. 큰 파일은 현재 파일의 전송 바이트와 전체 바이트를 표시하고, 폴더 탐색·메타데이터·확정처럼 전체량을 모르는 구간은 불확정 진행 상태로 표시한다. 폴더 전체 진행률로 오인할 백분율은 표시하지 않는다.

같은 디스크 안의 복사는 가능하면 복제(클론)로 즉시 끝나고 공간을 더 쓰지 않는다. 복제는 바이트 진행 없이 한 번에 끝나며 중간에 끊을 수 없다. 다른 디스크 복사는 기존처럼 취소 가능한 바이트 진행을 보여준다. 복제는 시작 전과 확정 직전에 취소를 확인하며, 취소되면 임시 항목을 정리하고 아무것도 확정하지 않는다.

취소 버튼은 파일 하나를 복사하는 도중에도 작동한다. 아직 확정하지 않은 복사본은 정리하고 원본과 기존 대상을 보존한다. 이미 시작한 확정·복구 구간은 중간에 끊지 않고 안전하게 마친다. 완료한 항목은 유지하며, 취소된 항목과 아직 시도하지 않은 항목을 구분한다.

첫 실패나 취소 이후 나머지 항목은 실행하지 않는다. 결과 창은 완료·건너뜀·실패·취소·미처리와 각각의 원본·목적지·복구 위치를 보여준다. 새 대상은 완성됐지만 이전 대상의 휴지통 이동이 실패한 경우도 경고를 표시한다. 다른 디스크에서 원본을 휴지통으로 보내지 못했다면 양쪽의 완성된 파일을 보존하고 실패로 보고한다.

파일 작업 중 추가 변경 명령은 이유를 안내하고 실행하지 않는다. 작업 중에는 창 닫기와 앱 종료도 완료 또는 취소 후 다시 시도하도록 안내한다.

## 휴지통과 만들기

목록에서 fn+Delete(앞으로 지우기) 또는 Cmd+Delete는 선택 항목을 휴지통으로 보낸다. Backspace 단독은 휴지통으로 보내지 않고 뒤로 간다. 이름을 바꾸는 중이면 Delete는 글자를 지운다.

새 폴더는 Cmd+Shift+N 또는 Ctrl+Shift+N이다. 새 텍스트 파일은 Cmd+Alt+N 또는 Ctrl+Alt+N이다. 둘 다 우클릭 메뉴에도 있다. 기본 이름은 `새 폴더`와 `새 텍스트 문서.txt`다. 이미 있으면 `새 폴더 (2)`처럼 번호를 붙인다. 새 폴더·새 텍스트 파일을 만들면 그 항목을 선택하고 이름 고치기를 시작한다.

휴지통으로 보내지 못한 항목은 그대로 남는다. 어느 항목이든 실패하면 `‘이름’을(를) 휴지통으로 보내지 못했습니다. 아무것도 지우지 않았습니다. (이유)`와 함께 보낸 항목 수와 남은 항목 수를 알려 준다. 첫 실패 뒤의 항목은 시도하지 않는다. 휴지통이 없는 디스크(일부 네트워크·외장 디스크)일 수 있으면 `이 디스크는 휴지통을 지원하지 않을 수 있습니다.`를 덧붙인다. 이 앱은 바로 지우지 않는다.

## 실행 취소

목록에 포커스가 있을 때 편집 > 실행 취소(Cmd+Z, Ctrl+Z)는 이 앱에서 한 마지막 파일 작업(휴지통 보내기, 이름 바꾸기, 옮기기, 복사, 새로 만들기, 압축)을 되돌린다. 이름을 바꾸는 중에는 파일 작업이 아니라 그 글상자의 글자 편집을 되돌린다. 메뉴 제목은 `실행 취소 <되돌릴 작업>`이다. 되돌릴 작업이 없거나 파일 작업이 진행 중이면 항목이 꺼진다. 다시 실행은 항상 꺼져 있다. 글상자에 포커스가 있으면 같은 키가 그 글상자의 글자 편집을 되돌린다. 작업은 최근 50개까지 쌓이고 앱을 끄면 사라진다.

되돌리기도 휴지통 보내기와 빈 자리로 옮기기만 한다. 덮어쓰거나 바로 지우지 않는다. 그 사이 항목이 바뀌었거나, 원래 자리에 다른 항목이 있거나, 휴지통 안의 항목이 다른 것으로 바뀌었거나, 항목을 확인할 수 없으면 그 항목은 건너뛰고 이유를 보여준다. 건너뛴 항목이 있어도 되돌린 항목은 그대로 두고, 같은 작업을 다시 쌓지 않는다. 바꾸기로 휴지통에 간 기존 항목은 되돌릴 때 제자리로 돌아온다. 다른 디스크로 옮긴 항목을 되돌리면 원본을 휴지통에서 꺼내고 옮긴 사본을 휴지통으로 보낸다. 건너뜀·실패·취소로 실제로 바뀌지 않은 항목과 같은 폴더로의 이동처럼 아무것도 바뀌지 않은 작업은 기록하지 않는다. 되돌린 항목은 목록에서 선택한다.

## 우클릭 메뉴

우클릭이나 두 손가락 탭은 위에서부터 열기, 다른 앱으로 열기 ▸, 새 폴더, 새 텍스트 파일, 잘라두기, 복사, 붙여넣기, 이름 바꾸기, 휴지통으로 옮기기, 압축, 경로 복사, 정보 보기, 터미널에서 열기를 보여 준다. 눌린 행이 선택에 없으면 그 행만 선택한다.

열기는 Enter와 같다. 다른 앱으로 열기 ▸는 선택한 항목을 모두 열 수 있는 앱을 고르게 하며, 기본 앱이 있으면 맨 위에 `(기본)`으로 표시한다. 고른 앱이 선택한 항목을 모두 연다. 열 수 있는 앱이 없으면 `없음`이 꺼진 채로 보인다.

경로 복사는 선택한 항목의 전체 경로를 한 줄에 하나씩 글자로 클립보드에 쓴다. 클립보드가 바뀌므로 복사해 둔 파일은 대체되고 잘라두기는 해제된다. 파일은 옮기지 않는다.

터미널에서 열기는 폴더 하나만 골랐으면 그 폴더에서, 그 밖에는 포커스 창의 현재 폴더에서 터미널 앱을 연다.

선택이 없으면 열기, 다른 앱으로 열기, 잘라두기, 복사, 이름 바꾸기, 휴지통으로 옮기기, 압축, 경로 복사, 정보 보기가 꺼진다. 압축과 정보 보기는 항목 하나를 골랐을 때만 켜진다. 터미널에서 열기는 항상 켜져 있다.

## 압축

압축은 선택한 항목 하나를 같은 폴더에 `이름.zip`으로 만든다. 이미 있으면 `이름 (2).zip`처럼 번호를 붙이고 기존 파일은 덮어쓰지 않는다. 만드는 동안 상태 막대에 진행 중임을 보이고 취소 버튼으로 멈출 수 있다. 멈추거나 실패하면 만들던 파일은 남기지 않는다. 실행 취소하면 zip을 휴지통으로 보낸다. 압축 중에는 다른 파일 작업을 시작하지 않는다.

## 정보 보기

Option+Return 또는 우클릭 메뉴의 정보 보기는 항목 하나의 정보를 읽기 전용 시트로 보여 준다. 이름, 종류, 크기(파일), 안에 든 항목 수(폴더, 바로 아래 단계만 세며 백그라운드에서 읽는다), 만든 날짜, 수정한 날짜, 전체 경로, 권한(`rwxr-xr-x (755)` 형식)이다. 목록에 포커스가 있을 때만 키가 동작하며, 글상자에서는 Option+Return이 그대로 글상자의 키다. 닫기 버튼, Esc, Return으로 닫는다.

## 드래그

목록 행을 끌어 폴더 행이나 다른 세션의 목록에 놓는다. 같은 디스크 안으로 끌어 놓으면 옮기고, 다른 디스크로 끌어 놓으면 복사한다. 여러 항목은 모두 같은 디스크일 때만 옮긴다. Option을 누르면 항상 복사하고, Cmd를 누르면 항상 옮긴다. 커서 표시와 실제 작업은 같다. Finder에서 끌어 온 항목도 같은 규칙이다. 이름 충돌 규칙은 붙여넣기와 같다. 조금만 움직여도 선택이 드래그로 바뀌지 않게, 일정 거리 이상 끌었을 때만 드래그가 시작된다.

## 양쪽 창

툴바에서 오른쪽 세션을 켜고 끈다. 목록이나 그 주소창을 누르면 그 세션이 포커스 창이 된다. 꺼져 있을 때 F5와 F6는 파일을 옮기지 않는다. 켜져 있을 때 F5는 포커스 창의 선택을 반대 세션으로 복사하고, F6는 옮긴다.

편집 메뉴와 목록 우클릭에도 반대쪽 폴더로 복사·이동 명령과 F5/F6 표시가 나온다. 명령은 반대쪽 폴더 이름을 표시하고 전체 대상 경로를 도움말로 제공한다. 양쪽 창이 꺼졌거나 선택이 없거나 파일 작업이 진행 중이면 비활성화된다. 기존 F5/F6와 같은 전송·충돌·취소·실행 취소 경로를 사용한다.

사이드바는 160–240pt 범위에서 유지하고 파일 창은 각각 최소 260pt를 확보한다. 양쪽 창을 켜면 가용 폭을 나눈다. 이름 열은 최소 180pt를 유지하며, 좁은 창에서는 나머지 열을 가로 스크롤로 본다.

## 다시 실행하기

좌우 창의 마지막으로 읽기에 성공한 경로, 정렬 열·방향, 숨김 표시와 양쪽 창 표시 여부를 저장한다. 진행 중인 탐색의 목적지는 저장하지 않는다. 다음 실행 시 저장된 경로를 비동기로 읽는다.

저장된 폴더에 접근하지 못하면 홈, 임시 폴더 순서로 서로 다른 후보를 한 번씩 시도하고 해당 창 아래에 복원 실패 이유와 대체 경로를 표시한다. 이후 사용자가 직접 이동하다 실패한 경우에는 자동으로 다른 폴더로 보내지 않는다. 잘라두기 의도와 진행 중인 파일 작업은 저장하거나 재실행하지 않는다.

## 다른 앱이 폴더·파일 보여 주기를 요청할 때

다른 앱이 폴더나 파일을 열어 달라고(열기) 하거나 보여 달라고(Finder에서 보기) 요청하면 이 앱이 포커스 창에서 처리한다. 앱이 꺼져 있었다면 창이 뜬 뒤에 처리하고, 최소화돼 있으면 되살려 맨 앞으로 가져온다. 요청의 경로는 심볼릭 링크를 따라간 실제 경로로 본다.

- 폴더이면 포커스 창이 그 폴더로 이동한다.
- 파일이거나 `.app` 같은 패키지이면 포커스 창이 그 항목이 든 폴더로 이동하고 그 항목을 선택한다.
- 여러 항목이 오면 처음으로 찾은 유효한 항목만 처리한다.
- 경로가 없으면 이유를 알리고 아무것도 바꾸지 않는다.

이 요청은 이동과 선택만 한다. 파일을 만들거나 옮기거나 고치지 않는다. 이전에 저장한 폴더를 복원하는 중이어도 이 요청이 우선한다. 이 앱을 기본 파일 뷰어로 쓰는 방법은 README에 있고, 시스템 설정은 사용자가 직접 바꾼다. 열기/저장 창, 데스크탑, Dock의 Finder 아이콘, Finder 경로를 고정해 둔 앱은 계속 Finder를 쓴다.

## 이번 범위 밖

파일 작업이 없을 때 Cmd+W는 창을 닫는다. 마지막 창이 닫히면 앱이 끝난다.

탭, 아이콘 보기, 열 보기, 하위 폴더까지 찾기, 파일 작업 다시 실행, 디스크에서 바로 지우기는 이 문서의 동작이 된 뒤에 이 파일을 고치면서 추가한다.
