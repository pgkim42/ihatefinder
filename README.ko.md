# IHateFinder

[English](README.md)

IHateFinder는 macOS용 파일 관리자입니다. 주소창에 경로를 입력하고, 파일을 찾고, 잘라두기와 붙여넣기로 옮깁니다. 두 목록 사이에서 파일을 옮기거나, 작업마다 별도 창을 열어 쓸 수 있습니다.

- 경로를 입력하면 폴더 후보를 보여줍니다.
- 현재 폴더의 이름을 거르거나 하위 폴더까지 검색합니다.
- 뒤로 가면 이전 선택, 스크롤 위치, 거르기를 복원합니다.
- 이미지와 PDF를 축소판으로 보거나 Quick Look을 엽니다.
- 파일 작업을 되돌립니다. 경로 충돌로 막힌 항목은 원인을 해결한 뒤 다시 시도할 수 있습니다.

## 빌드와 실행

macOS 14 이상과 Xcode에 포함된 Swift 도구가 필요합니다.

1. 저장소 루트에서 터미널을 엽니다.
2. 테스트를 실행합니다.

   ```bash
   make test
   ```

3. 앱을 빌드하고, 서명한 뒤 실행합니다.

   ```bash
   make run
   ```

`make run`은 `IHateFinder.app`을 만들고 이 맥에서 실행되도록 서명합니다. 앱을 열지 않고 빌드만 하려면 `make build`를 사용합니다.

데스크탑, 문서, 다운로드, 연결된 디스크에 접근할 때 macOS가 권한을 물을 수 있습니다. 해당 위치를 보려면 **허용**을 선택합니다. 접근을 거부하면 오류를 표시하고 이전 폴더에 머뭅니다.

## 폴더 탐색

**포커스된 목록**이 키보드 명령과 파일 작업을 받습니다. 목록이나 그 주소창을 클릭하면 해당 목록에 포커스가 갑니다.

| 단축키 | 동작 |
|---|---|
| Command-L | 주소창의 경로를 편집합니다. |
| 주소창에서 Return | 입력한 경로나 선택한 폴더 후보를 엽니다. |
| 목록에서 Return 또는 Command-아래 화살표 | 선택한 항목을 엽니다. |
| Backspace, Command-[ 또는 Option-왼쪽 화살표 | 뒤로 갑니다. |
| Command-] 또는 Option-오른쪽 화살표 | 앞으로 갑니다. |
| Command-위 화살표 또는 Option-위 화살표 | 부모 폴더로 이동하고, 방금 나온 폴더를 선택합니다. |
| Command-Shift-마침표 | 숨김 항목을 보이거나 숨깁니다. |

`~`는 홈 폴더를 뜻합니다. 경로를 입력하면 일치하는 폴더 후보가 나옵니다. 화살표로 후보를 고르거나 Tab으로 경로를 완성합니다. Return을 누르면 그 폴더로 이동합니다. Esc는 후보 목록을 닫고, 한 번 더 누르면 주소 편집을 취소합니다.

뒤로·앞으로 이동하면 각 방문 당시의 선택, 스크롤 위치, 거르기를 복원합니다. 그 사이 사라진 항목은 선택하지 않습니다.

Return은 선택한 폴더 하나 또는 선택한 파일들을 엽니다. 파일과 폴더가 섞여 있으면 파일만 엽니다. 파일을 20개 넘게 열 때는 먼저 확인합니다. 폴더 여러 개를 한꺼번에 열지는 않습니다.

주소창 아래의 폴더 이름을 클릭하면 그 위치로 바로 이동합니다. 상위 폴더로 이동하면 방금 나온 경로의 하위 폴더를 선택합니다. 현재 폴더를 클릭하면 선택과 이동 기록을 유지합니다.

### 이름 거르기와 검색

| 단축키 | 범위 |
|---|---|
| Command-F 또는 F3 | 현재 폴더에서 이름을 거릅니다. |
| Command-Shift-F | 현재 폴더와 하위 폴더에서 이름을 검색합니다. |

거르기 칸에 이름의 일부를 입력하면 일치하는 항목만 남습니다. 하위 폴더는 검색하지 않습니다. 메뉴 이름은 **이 폴더에서 이름 거르기**입니다.

하위 폴더까지 찾으려면 **하위 폴더에서 이름 검색**을 선택하거나 Command-Shift-F를 누릅니다. 결과에는 각 항목의 원래 위치가 나옵니다. 결과를 우클릭하고 **원래 폴더에서 보기**를 선택하면 그 폴더로 이동해 해당 항목을 선택합니다.

검색은 현재 숨김 항목 설정을 따릅니다. 시작 폴더가 심볼릭 링크를 거치면 실제 위치에서 검색합니다. 그 안에서 만나는 링크를 따라 다른 폴더로 들어가거나 앱 패키지 내부를 검색하지는 않습니다. 결과에서 파일을 열거나 원본 항목에 파일 작업을 할 수 있습니다.

두 입력 칸 모두 Return을 누르면 포커스가 목록으로 돌아갑니다. Esc는 거르기를 지우거나 검색을 끝냅니다. 새 검색어를 입력하면 이전 검색을 대체하고, 검색을 끝내면 진행 중인 검색도 취소합니다. 뒤로·앞으로 이동하면 검색어와 선택을 복원하며, 결과 정렬은 다시 검색하지 않고 선택을 유지합니다. 읽을 수 없는 하위 폴더가 있어도 나머지 결과와 함께 건너뛴 위치와 이유를 표시합니다.

### 양쪽 창과 별도 창

보기 메뉴에서 **양쪽 창**을 선택하거나 툴바 버튼을 누르면 목록이 하나 더 나옵니다. 각 목록은 폴더와 이동 기록을 따로 가집니다. F5는 반대쪽 목록으로 복사하고, F6는 옮깁니다.

Command-N은 별도의 창을 엽니다. 각 창은 목록, 선택, 파일 작업의 실행 취소 기록을 따로 가집니다. 클립보드와 즐겨찾기는 창 사이에서 공유합니다.

Command-W는 현재 창을 닫습니다. 마지막 창을 닫으면 앱이 종료됩니다. 파일 작업 중에는 작업을 끝내거나 취소한 뒤 해당 창을 닫거나 앱을 종료합니다.

### 즐겨찾기

1. 포커스된 목록에서 폴더를 엽니다.
2. 파일 메뉴나 우클릭 메뉴에서 **현재 폴더를 즐겨찾기에 추가**를 선택합니다.
3. 사이드바에 생긴 바로가기를 클릭해 폴더를 엽니다.

즐겨찾기를 우클릭하면 열기, 제거, 위로 이동, 아래로 이동을 선택할 수 있습니다. 변경 사항은 다른 열린 창에도 반영되고, 앱을 다시 실행해도 유지됩니다.

같은 경로를 두 번 추가해도 바로가기는 하나입니다. 바로가기를 제거해도 폴더는 바뀌지 않습니다. 즐겨찾기는 경로를 저장하므로, 다른 앱에서 옮기거나 이름을 바꾼 폴더를 자동으로 추적하지 않습니다.

## 파일 살펴보기

| 명령 | 동작 |
|---|---|
| Space 또는 Command-Y | 선택한 항목의 Quick Look을 열거나 닫습니다. |
| Quick Look에서 Esc | 미리보기를 닫습니다. |
| 보기 > **축소판 보기** | 큰 행에 파일 내용의 축소판을 표시합니다. 다시 선택하면 상세 목록으로 돌아갑니다. |
| Option-Return | 선택한 항목 하나의 정보를 보여줍니다. |

축소판 행에서는 이미지와 PDF 내용을 파일 정보와 함께 볼 수 있습니다. 어느 보기에서도 Quick Look을 사용할 수 있습니다.

정보 보기에는 이름, 종류, 날짜, 경로, 권한이 나옵니다. 파일은 크기를, 폴더는 바로 아래 항목 수를 표시합니다. 폴더 전체 용량을 계산하거나 권한을 바꾸지는 않습니다.

## 파일 작업

### 선택, 만들기, 이름 바꾸기

| 단축키 또는 마우스 조작 | 결과 |
|---|---|
| Command-A | 보이는 항목을 모두 선택합니다. |
| Shift-클릭 | 범위를 선택합니다. |
| Command-클릭 또는 Control-클릭 | 선택에 항목 하나를 더하거나 뺍니다. |
| 우클릭 또는 두 손가락 탭 | 메뉴를 엽니다. |
| F2 | 선택한 항목의 이름을 바꿉니다. |
| Command-Shift-N | 폴더를 만들고 이름 편집을 시작합니다. |
| Command-Option-N | 빈 텍스트 파일을 만들고 이름 편집을 시작합니다. |

Control-클릭은 선택을 바꾸며 메뉴를 열지 않습니다. 파일 이름을 바꿀 때는 확장자를 뺀 부분을 선택합니다. 폴더 이름과 점으로 시작하는 이름은 전체를 선택합니다.

새 항목의 기본 이름은 `새 폴더`와 `새 텍스트 문서.txt`입니다. 같은 이름이 있으면 번호를 붙입니다.

### 복사, 이동, 끌어다 놓기

| 단축키 | 동작 |
|---|---|
| Command-C 다음 Command-V | 포커스된 목록의 폴더로 복사합니다. |
| Command-X 다음 Command-V | 포커스된 목록의 폴더로 옮깁니다. |
| 목록에서 Esc | 거르기나 검색을 먼저 닫은 뒤 잘라두기를 취소합니다. 파일은 복사용으로 클립보드에 남습니다. |
| F5 | 반대쪽 목록으로 복사합니다. |
| F6 | 반대쪽 목록으로 옮깁니다. |

F5와 F6는 양쪽 목록이 보일 때 사용할 수 있습니다. 편집 메뉴와 우클릭 메뉴에도 같은 명령이 있으며, 대상 폴더 이름을 표시합니다.

Finder와 IHateFinder는 시스템 파일 클립보드를 사용합니다. 다른 앱에서 복사한 파일은 이동이 아니라 복사로 붙여넣습니다.

항목을 폴더나 반대쪽 목록으로 끌어다 놓을 수 있습니다. 같은 디스크에서는 이동하고, 다른 디스크에서는 복사하는 것이 기본 동작입니다. 끌기 시작한 앱이 허용하는 범위에서 Option을 누르면 복사하고 Command를 누르면 옮깁니다.

같은 이름이 있으면 다음 중 하나를 선택합니다.

- **바꾸기**: 대상 항목을 교체하고 기존 항목은 휴지통으로 보냅니다.
- **건너뛰기**: 해당 항목을 그대로 둡니다.
- **둘 다 유지**: 새로 들어오는 항목의 이름에 번호를 붙입니다.

충돌 창에는 양쪽 경로, 종류, 크기와 수정 시각이 나옵니다. 폴더 바꾸기는 대상 폴더 전체 교체이며 내용 합치기가 아닙니다. 같은 전송에서 남은 이름 충돌에도 선택을 적용하거나, **전체 작업 취소**로 완료한 항목을 유지한 채 나머지 전송을 중단할 수 있습니다.

### 진행 상태와 취소

전송 중에는 현재 항목과 항목 수를 보여줍니다. 전송량을 알 수 있으면 바이트 단위 진행 상태도 표시합니다.

**취소**를 누르면 전송을 멈춥니다. 완료한 항목은 유지합니다. 끝나지 않은 복사본은 원본 파일을 바꾸지 않고 정리합니다. 정리나 복구가 실패하면 결과에 남아 있는 파일의 위치를 표시합니다.

다른 디스크로 이동할 때는 복사 전후 원본을 확인합니다. 원본이나 그 하위 항목이 바뀌었거나 확인할 수 없으면 원본을 남기고 보존된 위치와 이유를 알려줍니다. 심볼릭 링크를 경유해도 폴더 자신이나 하위 폴더로 복사·이동할 수 없습니다.

macOS의 FAT/exFAT 볼륨처럼 원본 디스크가 안정적인 파일 식별 정보를 제공하지 않으면 다른 디스크로의 이동을 중단합니다. 대신 복사한 뒤 복사본을 확인하고 원본을 직접 정리할 수 있습니다.

결과는 완료, 건너뜀, 실패, 취소, 미처리를 구분합니다. 실패하거나 취소하면 뒤에 남은 항목은 처리하지 않습니다.

지원되는 APFS 볼륨 안에서는 복제 기능으로 복사합니다. 이 복사본은 처음에는 데이터 블록을 공유하지만, 나중에 내용을 바꾸면 디스크 공간이 더 필요할 수 있습니다.

### 휴지통과 실행 취소

Command-Delete 또는 fn-Delete는 선택한 항목을 휴지통으로 보냅니다. Backspace만 누르면 뒤로 갑니다. 파일을 영구 삭제하는 명령은 없습니다. 디스크가 휴지통을 지원하지 않으면 문제를 알립니다.

Command-Z 또는 Control-Z는 현재 창의 마지막 파일 작업을 되돌립니다. 휴지통으로 보내기, 이름 바꾸기, 이동, 복사, 만들기, 압축을 되돌릴 수 있습니다. 각 창은 최근 작업을 50개까지 보관합니다. 해당 창을 닫으면 기록도 사라집니다.

실행 취소는 다른 항목이 있는 경로를 덮어쓰지 않습니다. 경로 충돌이나 없는 부모 폴더 때문에 막힌 항목은 재시도할 수 있도록 남길 수 있습니다. 원인을 해결한 뒤 **편집 > 막힌 실행 취소 다시 시도**를 선택합니다. 장애물을 치우기 위해 수행한 이름 변경이나 이동은 되돌리지 않고, 막힌 작업만 다시 시도합니다. 이미 되돌린 항목은 반복하지 않습니다.

다른 디스크로 옮긴 파일을 되돌릴 때는 이동 후 수정한 내용도 보존합니다. 이전 원본 사본은 휴지통에 남을 수 있습니다. 같은 항목인지 확인할 수 없거나 다른 항목으로 바뀌었다면 건너뛰고 이유를 알려줍니다.

파일 작업의 다시 실행은 지원하지 않습니다. 글상자에서는 실행 취소와 다시 실행이 입력한 글자에 적용됩니다.

### 그 밖의 파일 명령

우클릭 메뉴에서 다음 명령도 사용할 수 있습니다.

- **다른 앱으로 열기**: 선택한 항목을 열 수 있는 앱을 고릅니다.
- **압축**: 선택한 항목 하나로 ZIP 파일을 만듭니다. 기존 압축 파일을 덮어쓰지 않습니다. 작업을 취소하거나 완료 후 되돌릴 수 있습니다.
- **경로 복사**: 전체 경로를 글자로 복사합니다. 클립보드 내용을 바꾸고 잘라두기를 취소합니다.
- **정보 보기**: 항목 하나의 정보를 엽니다.
- **터미널에서 열기**: 선택한 폴더나 현재 위치에서 터미널을 엽니다. 검색 결과에서는 원래 위치를 사용합니다.

열기, 다른 앱으로 열기, 터미널에서 열기가 실패하면 대상 경로와 이유를 표시합니다.

### Control 키로 조작하기

목록에 포커스가 있을 때는 C, X, V, A, L, F, Z, Shift-N, Option-N, Shift-마침표에 Command 대신 Control을 사용할 수 있습니다.

글상자에서는 Command와 Control 모두 C, X, V, A, Z를 지원합니다. Command-Z 또는 Control-Z에 Shift를 더하면 입력을 다시 실행합니다.

## 폴더 갱신과 앱 다시 실행

폴더는 백그라운드에서 읽습니다. 다른 앱이 폴더를 바꾸면 목록을 갱신합니다. 선택은 같은 파일에 유지하고, 지워진 파일은 선택에서 뺍니다.

앱을 다시 실행하면 저장된 작업 공간 하나를 복원합니다. 열려 있던 모든 창을 복원하지는 않습니다. 사용 중이던 창의 두 폴더 경로, 정렬, 숨김 항목, 양쪽 창 설정을 유지합니다.

저장된 폴더를 열 수 없으면 홈 폴더, 임시 폴더 순서로 시도합니다. 실패한 경로와 이유도 보여줍니다. 잘라두기, 진행 중인 전송, 파일 작업의 실행 취소 기록은 복원하지 않습니다.

## 기본 파일 뷰어로 쓰기

이 설정은 선택 사항이며 macOS 설정을 바꿉니다. IHateFinder가 자동으로 변경하지는 않습니다.

### 설정하기

1. `make build`를 실행합니다.
2. `IHateFinder.app`을 `/Applications`에 복사하고 한 번 엽니다.
3. 터미널에서 다음 명령을 실행합니다.

   ```bash
   defaults write -g NSFileViewer -string study.ihatefinder
   defaults write com.apple.LaunchServices/com.apple.launchservices.secure LSHandlers -array-add '{LSHandlerContentType="public.folder";LSHandlerRoleAll="study.ihatefinder";}'
   ```

4. 로그아웃한 뒤 다시 로그인하거나 맥을 재시동합니다.

이 설정을 따르는 앱은 폴더 열기와 ‘Finder에서 보기’ 요청을 IHateFinder로 보낼 수 있습니다. 폴더는 포커스된 목록에서 엽니다. 파일 요청은 부모 폴더를 열고 해당 파일을 선택합니다.

시스템의 열기·저장 창, 데스크탑, Dock의 Finder 아이콘은 바뀌지 않습니다. Finder를 직접 지정하는 앱도 계속 Finder를 열 수 있습니다.

### Finder로 되돌리기

1. 파일 뷰어 설정을 제거합니다.

   ```bash
   defaults delete -g NSFileViewer
   ```

2. 폴더 처리기 목록을 확인합니다.

   ```bash
   /usr/libexec/PlistBuddy -c "Print :LSHandlers" ~/Library/Preferences/com.apple.LaunchServices/com.apple.launchservices.secure.plist
   ```

3. `LSHandlerContentType = public.folder`이고 `LSHandlerRoleAll = study.ihatefinder`인 항목을 찾습니다. 번호는 0부터 시작합니다.
4. 해당 항목을 제거합니다. `<index>`를 그 번호로 바꿉니다.

   ```bash
   /usr/libexec/PlistBuddy -c "Delete :LSHandlers:<index>" ~/Library/Preferences/com.apple.LaunchServices/com.apple.launchservices.secure.plist
   ```

5. 로그아웃한 뒤 다시 로그인하거나 맥을 재시동합니다.

일치하는 IHateFinder 항목만 제거합니다. 여러 개라면 가장 큰 번호부터 작은 번호 순서로 제거합니다.

## 현재 한계

- 탭, 격자 아이콘 보기, 열 보기는 없습니다.
- 파일 작업의 다시 실행은 지원하지 않습니다.
- 파일을 영구 삭제하는 명령은 없습니다.
- 앱을 다시 실행할 때 열려 있던 모든 창을 복원하지는 않습니다.

## 개발 중 확인하기

`make test`는 파일 작업, 탐색, 검색, 경로 자동완성, 창별 명령 처리, 썸네일, 클립보드 동작을 검사합니다. 테스트는 임시 파일, 설정, 클립보드를 사용합니다.

어느 목록이 파일 명령을 받는지 확인하려면 다음을 실행합니다.

```bash
swift build && .build/debug/IHateFinder --repro-focus
```

출력에는 다음 줄이 있어야 합니다.

```text
copied=right-only.txt
pasteDest=right
backspace=goBack
forwardDelete=trash
```

이 확인은 오른쪽 목록에 포커스를 주고 명령의 대상을 검사합니다. 임시 파일과 별도 클립보드를 사용합니다. 파일 전송을 실행하거나 작업 공간을 저장하지는 않습니다.

세부 조작 규칙은 [동작 문서](docs/behavior.md)를 참고합니다.
