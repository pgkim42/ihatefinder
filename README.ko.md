# IHateFinder

[English](README.md)

IHateFinder는 맥용 파일 관리자입니다. 주소창, 상세 목록, 잘라두기와 붙여넣기로 파일을 옮깁니다.

이 문서는 ASD-STE100(간이 기술 영어)의 원칙을 한국어에 맞게 적용했습니다. 한 문장에는 한 가지 내용만 씁니다. 절차는 번호를 붙인 단계로 씁니다. 같은 대상에는 항상 같은 용어를 씁니다.

## 필요한 것

- macOS 14 이상.
- Xcode에 포함된 Swift 도구.

## 앱을 빌드하고 실행하기

1. 저장소 루트에서 터미널을 엽니다.
2. 테스트를 실행합니다:

   ```bash
   make test
   ```

3. 앱을 빌드하고, 서명하고, 엽니다:

   ```bash
   make run
   ```

`make test`는 파일 작업, 폴더 읽기, 세션 복원, 클립보드, 선택을 검사합니다. 테스트는 임시 폴더, 임시 설정, 임시 클립보드를 씁니다. 테스트는 사용자의 파일을 바꾸지 않습니다.

`make run`은 `IHateFinder.app`을 만들고, 이 맥에서 실행되도록 서명하고, 앱을 엽니다.

앱이 데스크탑, 문서, 다운로드를 처음 열면 macOS가 접근 권한을 묻습니다. **허용**을 클릭합니다. 허용하지 않으면 앱은 이 폴더들을 보여 주지 못합니다.

## 키와 마우스

이 절에서 "목록"은 키보드 포커스가 있는 상세 목록입니다.

목록에서 다음 키는 Command 대신 Control로 눌러도 같습니다: C, X, V, A, L, F, Shift-N, Option-N, Shift-마침표.

### 폴더로 가기

| 키 | 결과 |
|---|---|
| Command-L | 주소창에 커서를 놓습니다. |
| Return (주소창에서) | 그 경로의 폴더를 엽니다. |
| Return | 선택한 파일을 엽니다. 폴더 하나를 선택했으면 그 폴더로 들어갑니다. |
| Command-아래 화살표 | 선택한 항목을 엽니다. |
| Backspace | 뒤로 갑니다. |
| Command-[ 또는 Option-왼쪽 화살표 | 뒤로 갑니다. |
| Command-] 또는 Option-오른쪽 화살표 | 앞으로 갑니다. |
| Command-위 화살표 또는 Option-위 화살표 | 한 단계 위 폴더로 갑니다. 앱은 방금 있던 폴더를 선택합니다. |

파일을 여러 개 선택하고 Return을 누르면, 앱은 선택한 파일을 모두 엽니다. 20개보다 많으면 앱은 열기 전에 묻습니다. 파일과 폴더를 함께 선택하면 앱은 파일만 엽니다. 폴더만 두 개 이상 선택하면 앱은 아무것도 열지 않고 이유를 보여 줍니다.

### 복사하기와 옮기기

| 키 | 결과 |
|---|---|
| Command-C 다음 Command-V | 선택한 항목을 목록의 폴더로 복사합니다. |
| Command-X 다음 Command-V | 선택한 항목을 목록의 폴더로 옮깁니다. |
| Esc | 잘라두기를 취소합니다. 항목은 복사용으로 클립보드에 남습니다. |
| F5 | 선택한 항목을 반대쪽 목록으로 복사합니다. |
| F6 | 선택한 항목을 반대쪽 목록으로 옮깁니다. |

대상 폴더에 같은 이름의 항목이 있으면, 다음 중 하나를 고릅니다:

- **바꾸기**: 앱은 기존 항목을 휴지통으로 보냅니다.
- **건너뛰기**: 앱은 그 항목을 복사하지도 옮기지도 않습니다.
- **둘 다 유지**: 앱은 새 항목의 이름에 번호를 붙입니다.

Finder와 IHateFinder 사이에서 파일을 복사할 수 있습니다. 두 앱은 같은 시스템 클립보드를 씁니다.

### 끌어다 놓기

- 같은 디스크의 폴더로 끌면: 앱은 항목을 옮깁니다.
- 다른 디스크의 폴더로 끌면: 앱은 항목을 복사합니다.
- Option을 누르고 있으면: 앱은 항상 복사합니다.
- Command를 누르고 있으면: 앱은 항상 옮깁니다.

### 선택하기와 이름 바꾸기

| 키 또는 마우스 | 결과 |
|---|---|
| Command-A | 모든 항목을 선택합니다. |
| Control-클릭 | 항목을 선택에 더하거나 뺍니다. 메뉴는 열리지 않습니다. |
| 우클릭 또는 두 손가락 탭 | 메뉴를 엽니다. |
| F2 | 이름 바꾸기를 시작합니다. 앱은 확장자를 뺀 이름만 선택합니다. |
| Command-Shift-N | 새 폴더를 만듭니다. 바로 이름을 입력할 수 있습니다. |
| Command-Option-N | 빈 텍스트 파일을 만듭니다. 바로 이름을 입력할 수 있습니다. |
| Command-Shift-마침표 | 숨김 파일을 보이거나 숨깁니다. |

기본 이름은 `새 폴더`와 `새 텍스트 문서.txt`입니다.

### 휴지통

| 키 | 결과 |
|---|---|
| fn-Delete | 선택한 항목을 휴지통으로 보냅니다. |
| Command-Delete | 선택한 항목을 휴지통으로 보냅니다. |

앱은 항목을 항상 휴지통으로 보냅니다. 앱은 디스크에서 항목을 바로 지우지 못합니다.

일부 디스크에는 휴지통이 없습니다. 예를 들면 일부 네트워크 디스크와 일부 USB 디스크입니다. 이런 디스크에서 앱은 항목을 지우지 않습니다. 앱은 안내 메시지를 보여 줍니다.

### 실행 취소

목록에 포커스가 있을 때 Command-Z 또는 Control-Z는 마지막 파일 작업을 되돌립니다. 되돌릴 수 있는 작업은 휴지통으로 보내기, 이름 바꾸기, 옮기기, 복사, 새로 만들기, 압축입니다.

실행 취소는 안전한 두 가지 방법만 씁니다:

- 항목을 빈 자리로 옮깁니다.
- 항목을 휴지통으로 보냅니다.

실행 취소는 다른 항목을 덮어쓰지 않습니다. 작업 뒤에 항목이 바뀌었으면, 앱은 그 항목을 되돌리지 않습니다. 앱은 안내 메시지를 보여 줍니다.

글상자에 입력하는 중에는 Command-Z 또는 Control-Z가 입력한 글자를 되돌립니다. 이름을 바꾸는 중에도 같습니다. 파일 작업의 다시 실행은 없습니다.

### 미리보기, 거르기, 정보

| 키 | 결과 |
|---|---|
| Space 또는 Command-Y | 선택한 항목의 미리보기(Quick Look)를 엽니다. |
| Esc (미리보기에서) | 미리보기를 닫습니다. |
| Command-F 또는 F3 | 거르기 칸을 엽니다. 목록에는 이름에 그 글자가 들어 있는 항목만 보입니다. |
| Esc (거르기 칸에서) | 거르기를 지웁니다. |
| Option-Return | 항목의 정보를 보여 줍니다: 이름, 종류, 크기, 날짜, 경로, 권한. |

거르기는 현재 폴더만 봅니다. 하위 폴더는 보지 않습니다.
편집 메뉴의 이름은 **이 폴더에서 이름 거르기**입니다. 보기 메뉴와 우클릭 메뉴에도 **미리보기 (Space)**가 있습니다.

### 글상자

글상자에서 C, X, V, A, Z는 Command와 Control 모두 같게 동작합니다. Shift-Z는 입력을 다시 실행합니다.

### 메뉴

우클릭 메뉴에는 다음 명령이 있습니다:

- **열기**
- **다른 앱으로 열기**
- **새 폴더**, **새 텍스트 파일**, **잘라두기**, **복사**, **붙여넣기**, **이름 바꾸기**, **휴지통으로 옮기기**
- **압축**: `이름.zip`을 만듭니다. 기존 파일을 덮어쓰지 않습니다. 취소할 수 있고, 실행 취소할 수 있습니다.
- **경로 복사**: 전체 경로를 글자로 복사합니다.
- **정보 보기**
- **터미널에서 열기**
- **반대쪽으로 복사 (F5)**, **반대쪽으로 이동 (F6)**: 대상 폴더 이름을 보여 줍니다. 편집 메뉴에도 있습니다. 양쪽 창이 꺼져 있거나 선택이 없거나 전송 중이면 누를 수 없습니다.
- **현재 폴더를 즐겨찾기에 추가**

### 양쪽 창

**양쪽 창**을 클릭하면 목록이 하나 더 나옵니다. 목록을 클릭하면 그 목록에 키보드 포커스가 갑니다.

### 즐겨찾기

1. 포커스 창에서 폴더를 엽니다.
2. 파일 메뉴나 우클릭 메뉴에서 **현재 폴더를 즐겨찾기에 추가**를 고릅니다.
3. 사이드바의 즐겨찾기를 클릭하면 포커스 창이 그 폴더로 갑니다.
4. 즐겨찾기를 우클릭하면 **즐겨찾기 열기**, 제거, 위·아래 이동을 고를 수 있습니다.

순서는 다음 실행에도 남습니다. 같은 경로를 다시 추가해도 항목은 하나입니다. 즐겨찾기를 제거해도 원본 폴더는 옮겨지거나 지워지지 않습니다. 즐겨찾기는 절대 경로를 저장합니다. 다른 앱에서 폴더를 옮기거나 이름을 바꾼 경우에는 새 위치를 자동으로 추적하지 않습니다.


## 전송

복사하거나 옮기는 동안 앱은 다음을 보여 줍니다:

- 지금 처리하는 파일.
- 항목 수.
- 전송한 바이트 수(알 수 있을 때).

**취소**를 클릭하면 전송을 멈춥니다. 끝난 항목은 그대로 남습니다. 앱은 쓰다 만 파일을 남기지 않습니다.

모든 항목을 끝내지 못하면, 앱은 결과 목록을 보여 줍니다. 이 목록에는 건너뛴 항목, 실패한 항목, 취소된 항목, 처리하지 않은 항목이 나옵니다. 필요하면 복구 위치도 나옵니다.

같은 디스크 안에서 복사하면 거의 바로 끝나고 디스크 공간을 더 쓰지 않습니다. 앱은 이때 APFS 복제(clone)를 씁니다.

## 폴더와 다시 실행

앱은 폴더를 백그라운드에서 읽습니다. 다른 앱이 폴더를 바꾸면 목록에 그 변경이 나타납니다. 선택은 같은 항목에 남습니다.

앱을 다시 실행하면 같은 폴더를 엽니다. 정렬 순서, 숨김 파일 설정, 양쪽 창 설정도 그대로입니다. 저장한 폴더를 열 수 없으면 앱은 홈 폴더를 엽니다. 홈 폴더도 열 수 없으면 앱은 임시 폴더를 엽니다. 앱은 그 이유를 알려 줍니다.

## 기본 파일 뷰어로 쓰기

이 절차는 선택 사항입니다. 이 절차는 macOS 전체 설정을 바꿉니다. 앱은 이 설정을 바꾸지 않습니다. 다음 단계는 직접 해야 합니다.

### 준비

1. `make build`를 실행합니다.
2. `IHateFinder.app`을 `/Applications`에 복사합니다.
3. 앱을 한 번 엽니다.

### 설정

1. 터미널에서 다음 명령을 실행합니다:

   ```bash
   defaults write -g NSFileViewer -string study.ihatefinder
   defaults write com.apple.LaunchServices/com.apple.launchservices.secure LSHandlers -array-add '{LSHandlerContentType="public.folder";LSHandlerRoleAll="study.ihatefinder";}'
   ```

2. 로그아웃한 뒤 다시 로그인합니다. 또는 맥을 재시동합니다.

그 뒤로 다른 앱의 "Finder에서 보기"와 폴더 열기 요청이 IHateFinder로 옵니다:

- 폴더는 포커스가 있는 목록에서 열립니다.
- 파일은 그 파일이 든 폴더가 열리고, 앱이 그 파일을 선택합니다.

### 되돌리기

1. 다음 명령을 실행합니다:

   ```bash
   defaults delete -g NSFileViewer
   ```

2. LaunchServices 처리기 목록을 봅니다:

   ```bash
   /usr/libexec/PlistBuddy -c "Print :LSHandlers" ~/Library/Preferences/com.apple.LaunchServices/com.apple.launchservices.secure.plist
   ```

3. `LSHandlerContentType`이 `public.folder`이고 `LSHandlerRoleAll`이 `study.ihatefinder`인 항목을 찾습니다. 0부터 세어 그 항목의 번호를 구합니다.
4. 그 항목을 지웁니다. `<index>` 자리에 3단계의 번호를 넣습니다:

   ```bash
   /usr/libexec/PlistBuddy -c "Delete :LSHandlers:<index>" ~/Library/Preferences/com.apple.LaunchServices/com.apple.launchservices.secure.plist
   ```

5. 로그아웃한 뒤 다시 로그인합니다. 또는 맥을 재시동합니다. 그러면 Finder가 다시 파일 뷰어가 됩니다.

### 한계

다음은 계속 Finder를 씁니다:

- 열기 창과 저장 창.
- 데스크탑.
- Dock의 Finder 아이콘.
- Finder에 직접 요청을 보내는 앱.

## 이 버전에 없는 것

이 버전에는 다음 기능이 없습니다:

- 탭.
- 아이콘 보기와 열 보기.
- 하위 폴더까지 찾기.
- 파일 작업의 다시 실행.

## 오른쪽 목록 확인

이 확인은 포커스가 있는 목록으로 키가 가는지 검사합니다.

1. 저장소 루트에서 다음 명령을 실행합니다:

   ```bash
   swift build && .build/debug/IHateFinder --repro-focus
   ```

2. 출력에 다음 줄이 있는지 확인합니다:

   - `copied=right-only.txt`
   - `pasteDest=right`
   - `backspace=goBack`
   - `forwardDelete=trash`

이 확인은 오른쪽 목록에 키보드 포커스를 줍니다. 그다음 복사 원본과, 붙여넣기·Delete·F6의 대상을 검사합니다. 이 확인은 파일을 지우거나 옮기지 않습니다. 이 확인은 별도의 클립보드를 씁니다. 이 확인은 세션을 저장하지 않습니다.
